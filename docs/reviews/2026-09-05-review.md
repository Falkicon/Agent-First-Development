## Scope and method

Fresh parallel reviews covered correctness, security, concurrency and resource
handling, cross-language contracts, test quality, packaging, CI, dependencies,
examples, and documentation. GPT-6 Astra handled security and independent
runtime review; GPT-5.6 Sol handled general implementation and coverage;
GPT-5.6 Luna handled bounded adapter, state, wire-format, and packaging fixes.
Confirmed findings received GitHub issues and regression tests. Independent
review then checked the fixes and found additional lifecycle, request-validation,
and feature-configuration defects.

The original checkout's uncommitted Python parity changes were preserved. All
review work occurred in a separate worktree based on current main. No release,
tag, or package publication was performed.

## Most consequential findings

- Remote TypeScript execution bypassed the declared MCP exposure boundary on
  several routes. Discovery and execution now share the exposed command set,
  including grouped/lazy tools, batches, pipelines, RPC, and streaming.
- HTTP routes lacked consistent Host/Origin and body-size checks. The shared
  handler now validates requests before dispatch and bounds JSON bodies.
- The client used incompatible batch/stream conventions and discarded structured
  failures, obscuring recovery guidance and partial results.
- Advertised execution controls were not consistently enforced across the three
  languages. Batches now honor their supported concurrency, stop, and deadline
  controls; pipelines preserve positional results and reject unsupported parallel
  execution. Non-native Rust builds reject deadline options before execution.
- Malformed batch entries could run a write and then throw during aggregation,
  hiding the side effect. Request preflight rejects malformed envelopes before
  invoking handlers.
- Connection retries, stream readers, handoff generations, and refresh locks had
  ownership or cleanup gaps. Regression tests exercise cancellation and late
  callbacks, rather than only successful connection paths.
- The green quality gate was misleading: the file-size check scanned zero files,
  and an extra `--` prevented Vitest from enabling coverage. Both checks now run.

## Compatibility and migration

1. Remotely callable TypeScript commands must declare `expose: { mcp: true }`.
   The server now enforces the existing documented opt-in default. Direct
   execution still uses the internal registry. Public examples have been updated.
2. Configure `allowedHosts` for custom deployment hostnames and `allowedOrigins`
   for browser clients on another origin. See the server README for defaults and
   request-body limits. These checks are not an authentication system.
3. View-state handlers must implement exact `replace` semantics to advertise
   undo. Legacy merge-only handlers still support updates but do not offer a
   misleading undo action.
4. Parallel pipeline execution is not implemented; requesting it now returns
   `UNSUPPORTED_OPTION`. Rust deadlines require the default `native` feature and
   a Tokio runtime with time enabled. Without `native`, deadline options fail
   before any handler runs.
5. Optional auth integrations use explicit subpath imports. See the auth README
   for migration from root imports to `/react` and `/commands`.
6. Dependency ranges and the lockfile were refreshed within declared compatible
   ranges. Optional auth provider minimums were raised to patched versions.
   The root `@auth/core` override resolves 0.41.3, inside Convex Auth 0.0.95's
   declared `^0.41.1` peer range. The `convex>ws` override also stays inside its
   parent's declared range. No advisories were suppressed.

## Limits of the review

This is a repository review, not an exhaustive penetration test or production
deployment assessment. Provider adapters were tested against their structural
contracts; complete external OAuth/provider flows were not exercised. Zero
advisory matches reflect the current registry database and do not guarantee the
absence of vulnerabilities.

TypeScript cancellation is cooperative: handlers that ignore `AbortSignal` can
continue side effects after a deadline result. Local-storage refresh locks remain
best-effort because storage offers no atomic compare-and-swap. The documentation
states these limits. Performance work here addresses bounded concurrency,
backpressure, and resource cleanup; it does not claim production load-test results.
